# Images

Drop your headshot in this folder using **exactly** this filename:

- `profile.jpg`: used as the circular photo on the About section (and as the social-preview image). Save/export it as **JPEG**; browsers cannot display TIFF, so a `.tiff` file here will not load.

Until `profile.jpg` exists, the site automatically shows a placeholder "AV" avatar instead of a broken image icon. Once you add the real file, refresh the page (a hard refresh, Ctrl+Shift+R, if your browser cached the missing-image state) and it will replace the placeholder automatically. No code changes needed.
